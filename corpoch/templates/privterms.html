Corpo

Privacy and Terms

Corpo is a passion/hobby project. It will remain free to use, and never charge money.

Collected Information

Users

The only information collected from users are the public discord fields associated with your account. While logging into the main website does allow Corpo to read some of the information about the guilds you are in, this information is only used to check what guilds you're in that are also running a tournament so that it can retreieve your playstats (when updated to do so).

Guilds

If you invite Corpo to a discord guild, by-default it will collect no information from the guild. When a tournament is setup to run in a server, that then triggers the bot to start collecting the Channel Listing, Roles, and the public information. This is used to configure the tools to run in the right channels/etc.

Terms

For now, really just don't abuse the tools. If you've been given admin access into the system, behave. This service is provided to the Clone Hero Tournament community as a whole. The servers/resources involved need to be shared.

If you have questions or comments, feel free to join the CORPo Offices for help!
