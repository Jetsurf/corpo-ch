Corpo

Corpo is a Clone Hero tournament organizier tool used to assist with a lot of tasks involved in running one. This page will eventually have more information from Tournaments past and on-going.

Corpo Bot

The Corpo Discord Bot is a component of Corpo that handles matches, qualifiers, screenshot collection, and CHOpt/Hydra path generation.
/qualifier

Provides information on a running qualifier for a Discord Guild (Download links, forms, etc). Allows for submitting a qualifier screenshot to enter a tournament, and shows previous submissions.

/ch path

Will generate a CHOpt or Hydra (for Drums) path for either a chart listed on Encore or from a tournament's setlist (only ones the bot has ran for now)

About

Corpo is a passion project made by competitive Clone Hero players for everyone. It's primary aim is to make data on CH tournaments easily available.

It will always remain open-source, free to use, and collect as little information as possible.

For now, this is just a basic landing page. More to come. Questions, please reach out to @jetsurf on Discord.
